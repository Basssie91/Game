🔄 Records overzetten

Records worden in je browser bewaard. Met een code neem je ze mee naar een ander apparaat, een andere browser of je school-laptop. Je beste score blijft altijd bewaard, er gaat niets verloren.

1. Jouw code (op het apparaat mét je records)

Stuur de code naar jezelf (bijvoorbeeld via WhatsApp, Discord of mail) of zet hem in je notities als back-up.

2. Code plakken (op het nieuwe apparaat)
